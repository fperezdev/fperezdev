### How I work

- **Written-first:** you describe the task in writing; I reply with a mini plan, a fixed price and a delivery date — usually within 2 hours during US business hours.
- **Async, no calls:** written updates 2–3 times per week, a short demo video at handover, plus documentation and a deploy guide.
- **Numbers before adjectives:** if a module claims to be accurate, it comes with the set that proves it and the command that reproduces it.
- **Deterministic where money is involved:** amounts, percentages and scores are computed; the model writes the sentence around them, never the figures.
